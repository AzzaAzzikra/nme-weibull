# nmeweibull

<!-- badges: start -->
<!-- badges: end -->

The goal of nmeweibull is to provide an R implementation of the New Modified Exponential-Weibull (NME-Weibull) distribution. This package includes functions for evaluating the probability density function, cumulative distribution function, survival function, hazard function, quantile function, random number generation, parameter estimation using Maximum Likelihood Estimation (MLE), and risk measures including Value-at-Risk (VaR), Tail Value-at-Risk (TVaR), and Range Value-at-Risk (RVaR).

## Installation

If you receive this package as a compressed file, extract the file first. After extraction, make sure the package folder contains files such as DESCRIPTION, NAMESPACE, R/, man/, and README.md.

You can install the development version of nmeweibull from a local folder using the RStudio Console:

```r
install.packages("devtools")
devtools::install_local("C:/Users/YourName/Downloads/nmeweibull")
library(nmeweibull)
```

Replace "C:/Users/YourName/Downloads/nmeweibull" with the actual folder path where the package was extracted.

For example, if the package is extracted to the Downloads folder, the installation command may look like this:

```r
devtools::install_local("C:/Users/User/Downloads/nmeweibull")
library(nmeweibull)
```
